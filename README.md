The Hostel Allocation Management System is a console-based Java application designed to manage hostel room allocations efficiently. 
The system allows administrators to allocate students to available rooms, track room occupancy, and handle vacating operations while ensuring accurate database updates.
The application is built using Hibernate ORM for object-relational mapping and Oracle 21c Express Edition as the backend database
